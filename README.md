# Shanghai Trip 2026

Public, sanitized mobile itinerary for 2026-11-08 through 2026-11-11.

- Static single-file site
- No analytics or external UI dependencies
- No reservation numbers, contact details, payment data, eSIM data, QR codes, or source spreadsheet images
- Completion state stays only in the visitor's browser localStorage

Source spreadsheet and sanitized working files are intentionally excluded from this repository.
